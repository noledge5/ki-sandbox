# KI-Sandbox

Ein Mini-Sprachmodell für den Informatikunterricht (Realschule BW, Klasse 10): Schülerinnen und Schüler trainieren es mit
Texten, lassen es Wort für Wort schreiben und sehen bei jedem Wort, wie gezählt, gerechnet und gewürfelt wird.

- Eine einzige Seite (`index.html`), läuft ganz im Browser: ohne Konto, ohne Server, kein Text verlässt das Gerät.
- Veröffentlicht über GitHub Pages: https://noledge5.github.io/ki-sandbox/
